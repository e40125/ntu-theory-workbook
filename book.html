1. Read the language

The whole job of this course is to describe which inputs belong, then build a machine or a proof that gets that decision right. Before the machinery, we need to know what the objects are. Otherwise every formula turns into alphabet soup.

Symbols, strings, and languages

An alphabet, written Σ\SigmaΣ (“sigma”), is the finite set of symbols inputs may use. For Σ={0,1}\Sigma=\{0,1\}Σ={0,1}, the symbols are 0 and 1. A string is a finite ordered sequence of these symbols: 101 is one string. Its length is ∣101∣=3|101|=3∣101∣=3. The bars mean length, not membership or absolute value here.

A language is a set of strings. In E={1}E=\{1\}E={1}, the language has exactly one member: the one-symbol string 1. So 1 belongs; 11 does not. The letter E is just the name someone picked. Rename it A and the language stays the same. Braces collect members; they do not mean “repeat.”

Compare three different objects:

Expression What it is What it contains
1 A string One symbol
{1} A language One string, namely 1
1* as a regular expression A description of a language Zero or more consecutive 1s

The empty string, ε\varepsilonε, has zero symbols. The empty set, ∅\emptyset∅, has zero members. Thus {ε}\{\varepsilon\}{ε} has one member, a string of length zero. It's an empty package versus no package. Keep the analogy limited: the package corresponds to a member of a set.

Read a real slide's language

Pumping Lemma 1, page 1, uses

A={0n1n∣n≥0}.A=\{0^n1^n\mid n\geq0\}.A={0n1n∣n≥0}.

Read it as: “A is the set of strings made of n zeros followed by n ones, for any integer n at least zero.”

  • 0n0^n0n: n copies of 0, not the arithmetic number zero to a power.
  • Writing 0n1n0^n1^n0n1n side by side means concatenate: put the second string after the first.
  • The vertical bar inside the braces means such that. It plays a different role from the two length bars in ∣w∣|w|∣w∣.
  • The same n appears twice, so the two counts must agree.

Substitute n=0 to get ε. Substitute n=1 to get 01. Substitute n=2 to get 0011. 0101 has the same number of zeros and ones, but is not in A: the zeros must all come first. The order condition is doing real work.

Now change the rule to C={w∈{0,1}∗∣#0(w)=#1(w)}C=\{w\in\{0,1\}^*\mid \#_0(w)=\#_1(w)\}C={w∈{0,1}∗∣#0​(w)=#1​(w)}. Here #0(w)\#_0(w)#0​(w) counts zeros and #1(w)\#_1(w)#1​(w) counts ones. 0101 is in C. This is a changed language, not a new way to spell A.

Decode the glue

w∈Aw\in Aw∈A means “w is a member of A.” A⊆BA\subseteq BA⊆B means every member of A is also in B. The first compares a string with a language; the second compares two languages. A∪BA\cup BA∪B is union: strings in either language. A∩BA\cap BA∩B is intersection: strings in both.

AB={xy∣x∈A,y∈B}AB=\{xy\mid x\in A,y\in B\}AB={xy∣x∈A,y∈B} means choose a string from A and then one from B, in that order. If A={0,11} and B={1}, then AB={01,111}; BA={10,111}. No, concatenation is not a free-for-all shuffle.

A∗A^*A∗ means concatenate zero or more members of A. Zero choices produce ε, so ε always belongs to A*. For A={01}, A*={ε,01,0101,…}; 001 is not included. For A={0,1}, A* is every finite binary string. The base language changed, so the result changed.

What to write on an exam

For A={0ⁿ1ⁿ | n≥0}, a string belongs exactly when it consists of a block of zeros followed by a block of ones of the same length. The empty string is included by choosing n=0.

Notice that this sentence states both order and count, and handles the boundary n=0. That's the habit: unpack the rule into conditions before you draw anything.

A connected practice task

For B={0m1n∣m≥n≥0}B=\{0^m1^n\mid m\geq n\geq0\}B={0m1n∣m≥n≥0}, classify ε, 0, 001, 011, and 010. For each rejection, name the condition it violates. Then explain how B differs from A above.

Hint: find the two separate checks

First check whether the string is zeros-then-ones. Only after that compare the number of zeros with the number of ones. Zero-length blocks are allowed.

Show the worked answer

ε: yes (m=n=0). 0: yes (m=1,n=0). 001: yes (m=2,n=1). 011: no (1 is less than 2). 010: no (a zero occurs after a one). B permits extra zeros; A requires equality. Both require block order. A is a subset of B.

Keep: alphabet = allowed symbols; string = one ordered input; language = set of inputs. Membership depends on every condition in the definition.

2. What a machine remembers

A state is the machine's current memory summary. The circle is how we draw it. The name inside could be S, q₀, or 17; the name itself does not do the work. The transitions and accepting labels do.

A complete DFA for exactly 1

Target: E={1}E=\{1\}E={1}, input alphabet {0,1}\{0,1\}{0,1}. We need to accept exactly one input. Ask what information matters after each prefix:

  • S: nothing has been read yet.
  • A: the entire prefix read so far is exactly 1.
  • D: the prefix cannot possibly be completed into exactly 1.

S D A No
A D D Yes
D D D No

Read 11: start at S; first 1 takes you to A; second 1 takes you to D. You reject where you finish, not because you happened to pass through an accept state. The dead state loops on both symbols because extra input cannot fix an already-too-long string.

For ε, there are no moves and the machine stays at S, so it rejects. The start state matters even when nothing happens.

The five-part definition, with actual objects

M=(Q,Σ,δ,q0,F)M=(Q,\Sigma,\delta,q_0,F)M=(Q,Σ,δ,q0​,F):

  1. Q = {S,A,D}: all the states.
  2. Σ = {0,1}: input symbols.
  3. δ: the transition function, here given by the table.
  4. q₀ = S: one designated start state.
  5. F = {A}: the set of accepting states.

A DFA can have many accepting states. “One next state” describes each transition's output, not how many states can be in F. Formally δ:Q×Σ→Q\delta:Q\times\Sigma\to Qδ:Q×Σ→Q: give it one current state and one symbol; get one next state. A start state is one element of Q; that element can itself have a set-shaped label after a conversion. The label {q₀,q₁} can name one DFA state.

NFA: several possible runs

An NFA transition returns a set of possible next states. Its type is δ:Q×Σε→P(Q)\delta:Q\times\Sigma_\varepsilon\to\mathcal P(Q)δ:Q×Σε​→P(Q). Here Σε=Σ∪{ε}\Sigma_\varepsilon=\Sigma\cup\{\varepsilon\}Σε​=Σ∪{ε}; an ε move consumes no input. P(Q)\mathcal P(Q)P(Q) means all subsets of Q, including the empty set. For Q={u,v}, these are ∅, {u}, {v}, {u,v}.

So an entry {v} says “the available destinations form the set containing v.” Writing just v has the wrong type for this table. ∅ says that branch has no matching move. It does not add a mysterious extra NFA state called “null.”

Acceptance means at least one run reads the whole input and finishes accepting, with ε moves allowed. A dead branch doesn't kill the other branches. An ε arrow is optional; it does not force the machine to ignore a symbol arrow.

Subset construction, from scratch

Take the NFA with start u, accept v, and only arrow u —1→ v. The DFA tracks a set of current NFA possibilities. From {u}, 1 reaches {v}; 0 reaches ∅. From {v}, either symbol reaches ∅. From ∅, either symbol stays ∅.

The full power-set construction has four states. {u,v} is unreachable from {u}, so deleting it gives our three-state DFA. If a question requires the full prescribed construction, show all subsets first and then explain deletion. Reachable-only exploration is an efficient computation method, but it doesn't replace an explicitly requested four-state diagram.

With ε arrows, define ε-closure E(S): include S and everything reachable using only ε moves, repeatedly. Start at E({q₀}). For each real symbol, collect matching destinations from every current state, then take closure. Don't retain old states merely because they were there before.

Why this is the foundation for Midterm 2

A DFA has only finitely many memory summaries. A PDA adds a stack. A TM adds a rewritable tape and a head. The pumping argument asks what must happen when finitely many states face a sufficiently long input. Machine conversion asks how another representation can preserve the same decisions. Same game, different memory.

3. Build a proof from reasons

A proof is a chain of reasons that covers every case claimed. Examples help you discover an argument. They don't magically turn a claim about infinitely many inputs into something settled.

Start with the target, not fancy wording

Suppose the claim is: “If a DFA reaches the same state after strings u and v, then appending the same suffix z produces the same acceptance decision.”

What are you given? A deterministic machine, two runs ending at the same state, and one common remaining input z. What must you show? The final acceptance decisions agree. We don't need to remember the earlier strings; the current state plus the next symbol determines the next move.

Complete proof: Let q be the state reached after both u and v. The two remaining computations start at q and read the same string z. At each step, their current states and next input symbols are equal, so determinism gives equal next states. Hence their final states are equal. Since acceptance depends on whether that final state is in F, the decisions agree.

This is the engine behind the pumping lemma. Once you're back in the same state, the machine has no secret counter remembering how many laps you took. The circle is the memory. That's it.

Make the repeated-step reasoning explicit: induction

Induction proves a claim for every nonnegative integer by covering a starting case and a repeatable step. Think of a rule that lets you extend a correct run by one more symbol.

Claim: after k symbols of the common suffix above, the two machines are in the same state.

  • Base, k=0: neither suffix symbol has been read. Both states are q by assumption.
  • Induction hypothesis: assume the states agree after k symbols.
  • Step: if another symbol exists, both next symbols are the same symbol a. Apply δ to the same pair (state,a); the resulting states agree after k+1 symbols.
  • Conclusion: the states agree after all |z| symbols, including when |z|=0.

The hypothesis is a temporary assumption used to prove the next case. It is not permission to assume the final claim with no work. This pattern also proves a machine invariant: describe exactly what each state or stack represents after any processed prefix, verify the start, then verify every possible update.

Equality needs two directions

To prove a grammar generates exactly L, show:

  1. Soundness: every string the grammar generates is in L. No extra garbage gets through.
  2. Completeness: every string in L has a derivation. No valid input is excluded.

Worked example: S→0S1∣εS\to0S1\mid\varepsilonS→0S1∣ε generates exactly {0n1n∣n≥0}\{0^n1^n\mid n\geq0\}{0n1n∣n≥0}.

Soundness: A terminating derivation uses the wrapping rule some k≥0 times and then S→ε. Each wrap adds one 0 on the left and one 1 on the right, so the result is 0ᵏ1ᵏ.

Completeness: Take any 0ⁿ1ⁿ with n≥0. Apply S→0S1 exactly n times, then S→ε. This derives the chosen string. The two inclusions prove equality.

Contradiction and counterexamples

To prove L is not regular, assume it is regular and show this forces a statement incompatible with that assumption. You must name the contradiction. “This is impossible” is not a reason by itself.

To disprove “every binary string with equal counts is zeros-then-ones,” one counterexample suffices: 0101 has equal counts but is not in block order. You do not need to show that all equal-count strings fail. Which side says “every” matters.

∀\forall∀ means “for every”; ∃\exists∃ means “there exists.” Negating “every input is accepted” gives “some input is not accepted.” Negating “some input is accepted” gives “every input is not accepted.” Swap the quantifier and negate its claim. For P⇒QP\Rightarrow QP⇒Q, only P true and Q false is a counterexample.

How to discover a proof

Write the assumption and desired conclusion in ordinary English. Expand the relevant definition. Look at a tiny example to find what stays true. Then replace its particular numbers with arbitrary variables and justify the general step. Finally attack your own proof with boundary cases: zero, empty string, smallest permitted length, and a condition changed by one.

A construction proof supplies the required object and checks it. For example, to show every integer t between n and 2n is a sum of n numbers each 1 or 2: choose t−n copies of 2 and 2n−t copies of 1. The counts are nonnegative, sum to n, and their weighted sum is 2(t−n)+(2n−t)=t. Saying “clearly every value is possible” would skip exactly the part to prove.

Show the complete proof

Proof check before moving on: are the variables introduced, all cases covered, and every “there exists” backed by an actual object or argument? The formal proof should use clear English sentences, not a wall of symbols.

Pumping lemma

4. Why finite memory forces a loop

Question: how do we prove that no DFA, however cleverly designed, can recognize a language? Showing that your own three-state attempt fails isn't enough. Some other design might work. We need a restriction shared by every finite-state machine.

Why a loop is unavoidable

Suppose a DFA has p states. Reading its first p symbols visits p+1 states when you include the start. There are more visits than available states, so two visits must be to the same state. This is the pigeonhole principle: p boxes cannot hold p+1 objects with at most one in each.

Split an accepted input into x, y, z. x gets to the repeated state; y goes around the loop and returns; z is the rest of the input leading to acceptance. The loop consumes at least one symbol because the two visits occur at different times. It finishes within the first p input symbols.

Take a concrete conditional example: 00 [0] 111. Suppose the bracketed 0 loops back to the same state. Doing that loop twice gives 00 [00] 111; doing it zero times gives 00 [] 111, or 00111. All three computations reach the same state before the final 111, so the same suffix leads to acceptance. Yet only 000111 has equal numbers of zeros and ones. This explains the mechanism. It does not claim every DFA has its loop at this exact position.

The theorem, translated before use

If A is regular, there exists an integer p≥1 such that every s in A with |s|≥p has a split s=xyz satisfying:

∣y∣>0,∣xy∣≤p,xyiz∈A for every integer i≥0.|y|>0,\qquad |xy|\leq p,\qquad xy^iz\in A\text{ for every integer }i\geq0.∣y∣>0,∣xy∣≤p,xyiz∈A for every integer i≥0.

  • p: the pumping length; the hypothetical machine supplies it.
  • s: one sufficiently long accepted string.
  • x: prefix before the loop; may be empty.
  • y: the nonempty loop's input.
  • z: suffix after the loop; may be empty.
  • i: number of copies of y. i=0 deletes y; i=1 leaves the input alone; i=2 duplicates y.

The condition is necessary for regularity. A failed attempt to break pumping does not prove a language regular. To prove regular, construct a DFA, NFA, regular expression, or use a valid closure argument.

A complete exam proof

Claim: A={0n1n∣n≥0}A=\{0^n1^n\mid n\geq0\}A={0n1n∣n≥0} is not regular.

Suppose A is regular, and let p≥1 be a pumping length. Choose s=0ᵖ1ᵖ. Then s∈A and |s|=2p≥p. Consider any split s=xyz with |xy|≤p and |y|>0. Because the first p symbols of s are zeros, y=0ᵏ for some 1≤k≤p. Set i=0. Then xy⁰z=0ᵖ⁻ᵏ1ᵖ has fewer zeros than ones, so it is not in A. This contradicts the pumping property. Therefore A is not regular.

5. Make the pumping proof adapt

The first pumping proof teaches the structure. Exam rigor means recognizing what changes when the language changes. This lesson uses the course's square-length example and the 2021 paper's variations. The explanations are newly written; use the linked paper for its exact wording.

Square lengths: don't confuse a string with a number

D={1n2∣n≥0}D=\{1^{n^2}\mid n\geq0\}D={1n2∣n≥0} contains ε, 1, 1111, nine ones, sixteen ones, and so on. The string is made only of ones. The length must be a perfect square. 111 is out because three is not a square.

Assume regularity and get p≥1. Choose s=1ᵖ². It is long enough because p²≥p. Every legal y is 1ᵏ with 1≤k≤p. With i=2, the new length is p²+k, so

p2<p2+k≤p2+p<(p+1)2.p^2<p^2+k\leq p^2+p<(p+1)^2.p2<p2+k≤p2+p<(p+1)2.

There is no square strictly between two consecutive squares. Thus the pumped string is outside D for every legal k. That completes the contradiction.

Why choose p²? We need a member of D. Choosing 1ᵖ would fail when p isn't a square. Why use an inequality? It covers all possible loop lengths simultaneously.

The 2021 variation: can i=3 work?

Yes. Three copies replace the original one copy, so the increase is 2k, not 3k:

p2<p2+2k≤p2+2p=(p+1)2−1<(p+1)2.p^2<p^2+2k\leq p^2+2p=(p+1)^2-1<(p+1)^2.p2<p2+2k≤p2+2p=(p+1)2−1<(p+1)2.

Still trapped between adjacent squares. Same strategy; a changed calculation.

With i=0 and the same s, the length is p²−k. For p≥2,

(p−1)2<p2−p≤p2−k<p2.(p-1)^2<p^2-p\leq p^2-k<p^2.(p−1)2<p2−p≤p2−k<p2.

But when p=1, deleting y leaves ε. For n≥0, ε belongs to D, so this particular i=0 argument has a hole. If the problem changes the language to n≥1, ε is excluded and that last case works too. If a question fixes s or asks you to adapt the lecture proof, follow that restriction instead of silently replacing the setup.

Inequalities: choose a string on the boundary

2021 Problem 3(b) asks about L={0h1k∣h>5k, h,k>0}L=\{0^h1^k\mid h>5k,\ h,k>0\}L={0h1k∣h>5k, h,k>0}. The target has a strict inequality. Pick the nearest valid boundary: s=0⁵ᵖ⁺¹1ᵖ. Every legal y=0ᵗ for 1≤t≤p. Deleting y leaves h=5p+1−t≤5p=5k, violating h>5k. The original s is in L and long enough; every split is covered. Therefore L is not regular.

A random string with a huge excess of zeros might survive deletion of a short y. Choosing the boundary makes the smallest legal deletion fatal. That's how to discover s instead of memorizing it.

Ratios: turn words into counts

2021 Problem 3(a) uses nonempty binary strings with proportion of ones at most 0.9. Choose s=1⁹ᵖ0ᵖ, exactly on the allowed boundary. Any legal y=1ᵗ, 1≤t≤p. Pumping with i=2 gives proportion

9p+t10p+t>910,\frac{9p+t}{10p+t}>\frac9{10},10p+t9p+t​>109​,

because multiplying by the positive denominators reduces this to 90p+10t>90p+9t, which holds since t>0. The length remains nonzero. Thus every legal split can be broken and the language is nonregular.

Logic behind the theorem

The pumping conclusion has the pattern “there exists p, for every long member s, there exists a legal split, for every i the pumped string stays in L.” To contradict it: for every proposed p, exhibit a long member s for which every legal split has some failing i.

In the 2021 truth-table question, ¬(A∧B∧C)\neg(A\land B\land C)¬(A∧B∧C) is equivalent to (A∧B)⇒¬C(A\land B)\Rightarrow\neg C(A∧B)⇒¬C. Both are false only when A,B,C are all true. If asked for a detailed truth table, that verbal argument is not the requested deliverable: write all eight rows.

Grammars

6. Build strings with a grammar

A grammar builds a string. A machine reads a string. We will later convert between them while preserving the language. First, make the building process concrete.

One course example, every symbol explained

CFG 1, pages 2–5, gives:

A→0A1∣B,B→#.A\to0A1\mid B,\qquad B\to\#.A→0A1∣B,B→#.

A and B are variables: unfinished work you may replace. 0, 1, and # are terminals: actual symbols in the finished input. Here # is literally a separator character, not a counting operator. The start variable is A. The vertical bar means “or”: A may be replaced by 0A1 or by B.

The four-part formal grammar is G=(V,Σ,R,S)G=(V,\Sigma,R,S)G=(V,Σ,R,S). V={A,B} is the variable set. Σ={0,1,#} is the terminal alphabet. R is the set of rules above. S=A says that the chosen start variable is A. The formal slot is conventionally called S; the actual symbol occupying it need not be named S.

To generate 00#11:

A⇒0A1⇒00A11⇒00B11⇒00#11.A\Rightarrow0A1\Rightarrow00A11\Rightarrow00B11\Rightarrow00\#11.A⇒0A1⇒00A11⇒00B11⇒00#11.

At each arrow replace exactly one variable occurrence using a rule. Everything around it stays put. The last line has only terminals, so it is a finished string. ⇒\Rightarrow⇒ means one derivation step; ⇒∗\Rightarrow^*⇒∗ means zero or more steps. A rule arrow →\to→ states an allowed replacement; a derivation arrow ⇒\Rightarrow⇒ applies one inside a whole string.

Why this language is exactly 0ⁿ#1ⁿ

Each A→0A1 adds a matching outer pair. A→B and B→# end the wrapping with a separator. Any finished derivation therefore gives 0ⁿ#1ⁿ for some n≥0. Conversely, for any n≥0, take n wrapping steps then the two finishing steps. This proves both directions. With n=0, the string is #, not ε.

The recursive variable keeps the two distant blocks linked. That's the extra power compared with a finite-state memory. The grammar can nest arbitrarily many pending matching pairs.

Designing a grammar: decide what a rule contributes

Target 0n1n0^n1^n0n1n, n≥0: S→0S1 adds a matched pair, S→ε ends with zero pairs.

Target all strings made of balanced parentheses: S→(S) | SS | ε. The wrap nests one balanced string; SS puts two balanced strings side by side. A string like ()() needs the concatenation rule. A string like )( is excluded even though the counts agree. Count alone doesn't establish correct nesting.

Target 0n1n∪1n0n0^n1^n\cup1^n0^n0n1n∪1n0n: use separate variables A→0A1|ε and B→1B0|ε, then S→A|B. The start chooses which entire pattern to generate. It doesn't mix the two patterns midway.

Read a bigger grammar from the inside out

The 2023 paper starts with B→bB|ε and D→cD|ε. These generate b* and c*: any nonnegative count. X→aXb|ab generates aⁱbⁱ with i≥1. The base ab excludes ε.

Then Y→aBc|aYc generates aⁱbʲcⁱ with i≥1,j≥0: each wrap adds one a and one c, and B freely chooses the b count. Grammars

7. One string, two structures

Ambiguity asks whether one finished string has two different grammatical structures. It does not ask whether two different strings can be generated. Of course a useful grammar usually generates lots of strings.

Why “two derivations” alone is too weak

Take S→AB, A→a, B→b. You can expand A before B or B before A. Both routes make ab, but they describe the same parse tree: S has children A and B, and those become a and b.

To remove this irrelevant choice of expansion order, require a leftmost derivation: at each step replace the leftmost remaining variable. A grammar is ambiguous if some string has two distinct leftmost derivations, equivalently two distinct parse trees. One leftmost and one rightmost derivation do not automatically prove ambiguity.

A whole example from the 2022 paper

Grammar: H→bCb; C→mC | CbC | ε. Terminals b and m represent bread and meat. The start H is the whole hamburger. The string bmbmb can be built in these two leftmost ways:

H⇒bCb⇒bmCb⇒bmCbCb⇒bmbCb⇒bmbmCb⇒bmbmb.H\Rightarrow bCb\Rightarrow bmCb\Rightarrow bmCbCb\Rightarrow bmbCb\Rightarrow bmbmCb\Rightarrow bmbmb.H⇒bCb⇒bmCb⇒bmCbCb⇒bmbCb⇒bmbmCb⇒bmbmb.

H⇒bCb⇒bCbCb⇒bmCbCb⇒bmbCb⇒bmbmCb⇒bmbmb.H\Rightarrow bCb\Rightarrow bCbCb\Rightarrow bmCbCb\Rightarrow bmbCb\Rightarrow bmbmCb\Rightarrow bmbmb.H⇒bCb⇒bCbCb⇒bmCbCb⇒bmbCb⇒bmbmCb⇒bmbmb.

In the first route, the outer C first uses mC, then that remaining C splits into CbC. In the second, the outer C splits immediately, and the left child contributes the first meat. These are different structural choices, not merely doing the same independent replacements in another order. Every step shown replaces the leftmost variable, and both routes end at the identical terminal string.

That's a complete ambiguity witness. You don't need to show every string is ambiguous. The definition needs one witness.

Nullable rules can hide ambiguity

If B→BB|b|ε, the variable B can disappear directly or split and have both children disappear. So even a very short terminal string may have multiple parse structures. In the 2024 paper, S→B|BJ and J→jJb|j|ε. The string j has:

S⇒BJ⇒J⇒jS\Rightarrow BJ\Rightarrow J\Rightarrow jS⇒BJ⇒J⇒j

and

S⇒BJ⇒BBJ⇒BJ⇒J⇒j.S\Rightarrow BJ\Rightarrow BBJ\Rightarrow BJ\Rightarrow J\Rightarrow j.S⇒BJ⇒BBJ⇒BJ⇒J⇒j.

The second route has an extra B→BB subtree. Deleting ε from a written string does not delete that historical tree structure. This is why identical-looking intermediate strings can occur in distinct derivations.

Grammar versus language

“G is ambiguous” is a statement about this grammar. It does not prove its language has no unambiguous grammar. A language is inherently ambiguous when every CFG for it is ambiguous. That is a stronger claim requiring a different argument. Don't upgrade the conclusion just because the wording sounds similar.

How to work an ambiguity problem

Identify a string that can be split in two ways, or produced by two alternative start branches, or gets redundant nullable subtrees. Write two complete leftmost derivations. Underline the leftmost variable mentally before each step. Check the final terminal strings match exactly. State that the derivations are distinct and therefore the supplied grammar is ambiguous.

For arithmetic expressions, E→E+E|E×E|a permits different parse grouping of a+a×a. A grammar separating expression, term, and factor can impose precedence. It's the grammar structure doing the disambiguation; just writing “multiply first” beside an ambiguous grammar does not change its rules.

8. CNF without losing a rule

Chomsky normal form (CNF) is a standardized shape for grammar rules. The language should stay the same; the grammar's internal machinery changes. This is a repeat procedure on all six inspected Midterm 2 papers.

The destination

Each rule must have one of these shapes:

  • A→BC: exactly two variables on the right.
  • A→a: exactly one terminal on the right.
  • The start variable alone may have S₀→ε, if ε is in the language.

The start variable must not occur on the right of any rule. A→B is a unit rule and is not CNF. A→aB is not CNF because the two-symbol right side contains a terminal. A→BCD is not CNF because it has three variables. A→a is already fine; don't “fix” it into a unit rule.

Step 1: protect the start

Add a fresh start S₀ and S₀→S. “Fresh” means a symbol not already used. Keep S as an ordinary variable if needed. This lets us preserve ε using only S₀→ε and prevents the actual start symbol from being on a right side.

Step 2: eliminate ε rules without losing their choices

A variable is nullable if it can derive ε, possibly through other variables. Find them to a fixed point: first direct ε rules, then rules whose entire right side consists of nullable variables. Repeat until no new variable qualifies. Terminals never disappear this way.

For every right side, retain the original and add alternatives omitting each possible collection of nullable occurrences. Then remove ordinary ε rules; keep S₀→ε exactly when the original language contains ε.

The word “occurrences” is doing work. If A is nullable and a rule is S→ABA, the left A and right A are separate positions. Omitting one or both yields BA, AB, B, besides ABA. If B is nullable too, also AA, A, and ε are possible; duplicates count once. Keep ε only under the permitted start rule in the finished grammar.

The earlier gap, explicitly: for S→ABC with nullable A and B but nonnullable C, the alternatives are ABC, BC, AC, C. A stays/B disappears gives AC. Both disappear gives C. The C never disappears because no rule says it can.

Step 3: remove unit rules

A→B means A delegates to B without adding any terminal. Replace this delegation by B's non-unit alternatives. Keep B's productions for other uses of B. For chains and cycles, compute everything reachable by unit steps, then copy non-unit right sides from every reachable variable. This avoids looping on A→B→A.

Example: A→B, B→C|b, C→A|c. Each of A,B,C reaches all three through unit steps, so each receives alternatives b|c. Delete the unit links. The grammar becomes A→b|c, B→b|c, C→b|c.

The wording on CNF 2 page 3 can misleadingly suggest deleting the target variable's productions. That is not the language-preserving procedure. The worked examples and historical solutions retain productions needed by other variables. We implement the correct construction here.

Step 4: split long right sides and isolate terminals

For A→BCD, introduce X→CD and replace the original by A→BX. For A→aBb, introduce terminal helpers U→a,V→b, then use A→UX and X→BV. A prescribed exam order may split before replacing terminals; follow the requested stages and names. The final shape alone is not all the requested work.

A small complete conversion

Start with S→aSb|ε. Add S₀→S. Nullable S means add S→ab and S₀→ε; remove S→ε. Now:

S₀ → S | ε
S  → aSb | ab

Remove the unit S₀→S by copying S's non-unit alternatives:

S₀ → aSb | ab | ε
S  → aSb | ab

Introduce U→a,V→b,X→SV:

S₀ → UX | UV | ε
S  → UX | UV
X  → SV
U  → a
V  → b

Every rule now passes the shape test; S₀ never appears on the right. The UV base handles one pair; UX recurses; S₀→ε handles zero pairs.

Why the transformations preserve the language

For ε elimination, each omitted occurrence represents a subtree that previously derived ε. A derivation in the new grammar can restore those omitted ε subtrees; an old derivation can remove them. For unit elimination, copied rules compress a finite chain of unit steps; expand the chain to recover the old derivation. Helpers merely group a long right side or name a terminal. These are explanations for arbitrary derivations. Testing short strings can catch a mistake, but it cannot prove grammar equality for all lengths.

A PDA is an NFA with a stack. The stack can grow without a fixed bound, but only its top is accessible. Last item pushed is first item popped. That restriction is why it naturally matches nested structures and reversed strings.

Decode one arrow completely

An arrow labeled 1, 0 → ε means: consume input 1; require and remove a 0 at the stack top; push nothing. Three positions, three different jobs.

For an NFA or PDA, one complete accepting path proves acceptance. To prove rejection by tracing, every possible path must fail. When the question specifically requests a simulation tree, draw the branching even if you already see a winning path. 13. Turn balanced runs into grammar rules

This direction looks scarier because one grammar variable represents an entire balanced piece of a computation, not one machine state. The recipe is mechanical once that meaning is clear. It appears on all six inspected Midterm 2 papers.

First normalize the PDA

The course construction requires: one accepting state; empty stack on acceptance; each transition pushes one symbol or pops one symbol, never both and never neither.

A general final-state PDA doesn't automatically have these properties. Use a fresh bottom marker $ and a new start that pushes it. From each old accepting state, allow an ε move into a new drain state. The drain pops working symbols, then pops $ into the sole new accept state. Old accepting states cease to be accepting.

Why a separate drain? If you add free pops to the old states, the machine may throw away stack data and then continue its ordinary input-reading transitions, accepting extra strings. Once in the drain, it must never return to the computation. Entering the drain early cannot accept a longer input because the drain consumes no more real input.

A replace transition a,X→Y becomes a,X→ε into a private intermediate state, then ε,ε→Y into the destination. A no-stack-change transition a,ε→ε becomes a,ε→D followed by ε,D→ε through a private intermediate state, using a permitted dummy symbol D. Respect restrictions on Γ and on extra states; past questions often require reusing available symbols or states. A fresh marker is the safe unrestricted construction, not permission to violate a constrained problem.

What Aₚq means

For each ordered state pair p,q, make a variable Aₚq. It generates strings that can carry the machine from p to q with no net stack change while leaving any pre-existing stack below that computation untouched. Merely returning to the same stack after messing with its old contents is not the intended balanced segment.

The grammar's start is Aₛf, where s is the normalized start and f the sole accept state. If there are four PDA states, there are 4×4=16 variables. Sixteen variables is not sixteen steps and not a requirement to draw a sixteen-state automaton. Each variable names a different start/end pair.

  1. Do nothing: Aₚp→ε for every p.
  2. Join two balanced segments: Aₚq→AₚrAᵣq for every p,q,r.

Conversely, each grammar rule combines actual balanced runs, so induction on the derivation yields a valid run. The start/end normalization then makes generated strings exactly accepted inputs.

14. Check determinism properly

“Deterministic” means there is no choice between simultaneously applicable moves. For PDAs, checking only “one destination per table cell” is not enough: an input move and an ε move in different cells can both be applicable.

The four-way conflict

Suppose the current state is q, next input symbol is a, and top stack symbol is X. All four kinds of transitions could apply:

δ(q,a,X),δ(q,a,ε),δ(q,ε,X),δ(q,ε,ε).\delta(q,a,X),\quad\delta(q,a,\varepsilon),\quad\delta(q,\varepsilon,X),\quad\delta(q,\varepsilon,\varepsilon).δ(q,a,X),δ(q,a,ε),δ(q,ε,X),δ(q,ε,ε).

They respectively read/pop, read/no-pop, no-read/pop, no-read/no-pop. Recall that “no-pop” does not mean “stack empty.” Therefore δ(q,0,ε) and δ(q,ε,$) conflict when the next input is 0 and the stack top is $. Different columns don't save you.

The course convention, DPDA 1 page 4, requires exactly one of these four entries to be nonempty for each q,a,X, with a∈Σ and X∈Γ. Entries output a single pair (state,push-symbol), not a set of pairs. Reject-state completion is used for missing combinations. Other texts often use a partial-transition “at most one” formulation; follow this course's table convention on its exams.

A complete small example

Language: B={0m1n∣m≥n≥0}B=\{0^m1^n\mid m\geq n\geq0\}B={0m1n∣m≥n≥0}, from 2020 Problem 2. Let q₀ push a 0 on each input 0. On the first 1, pop a 0 and enter q₁. In q₁, each 1 pops a 0. A later 0 must reject because block order would break. Both q₀ and q₁ are accepting: leftover zeros are allowed, and n may be zero.

With stack alphabet Γ={0}, the nonempty DPDA entries are:

State Input Pop Output
q₀ 0 ε (q₀,0)
q₀ 1 0 (q₁,ε)

All other entries are ∅. For each real input symbol and possible stack top 0, exactly one relevant entry is nonempty. If the stack is actually empty and the next symbol is 1, the pop-0 instruction can't be executed, so the input is rejected. The sink's ε loop is rejection by failing to read the remaining input; qᵣ is never accepting.

For 001, the run ends in q₁ with one 0 still on the stack. It accepts. Final-state PDA acceptance does not generally require an empty stack. We enforce empty-stack finishing in some constructions because that particular language or conversion needs it.

Why a PDA is not always convertible to an equivalent DPDA

DFA and NFA recognize the same languages. PDA and DPDA do not: deterministic context-free languages form a proper subclass of context-free languages. Subset construction cannot solve this by making each possible stack configuration a finite state; stacks have unbounded length, so there may be infinitely many configurations.

A fixed stack bound is different. If a PDA is guaranteed to use at most m stack cells, there are finitely many stack strings, and an NFA can use states (q,stack). Start (q₀,ε), accept all pairs whose q is accepting, and simulate each legal stack update. This is the idea behind 2022 Problem 4(b). The bound must be uniform over all inputs; saying each individual run uses finitely many cells is not enough.

15. Design under exam constraints

The recurring exam move is: give you an unfamiliar count condition, restrict the states or alphabet, and ask you to turn it into a machine. Memorizing “push zeros, pop ones” won't cover all those variations. The useful habit is to translate the condition into units of stack work.

Weighted counts: a complete derivation

2022 Problem 2 uses 0ᵐ1ⁿ with 0.5n≤m≤1.5n, for nonnegative integer m,n. Multiply the condition by 2: n≤2m≤3n. This suggests pushing two markers per zero, then popping 1,2,or3 markers for each one. Successful emptying means the total number popped is exactly 2m.

But why can every total in that interval be achieved? Write t=2m. If n≤t≤2n, choose t−n twos and 2n−t ones. These counts are nonnegative, sum to n, and sum in value to t. If 2n≤t≤3n, choose t−2n threes and 3n−t twos; again n choices with total t. This proves the “if the inequality holds, a successful set of choices exists” direction. The other direction follows since n numbers each between 1 and 3 sum to a value between n and 3n. For n=0, the inequality forces m=0 and the empty sum works.

A seven-state PDA plan

Use states s,p,h,r,u,v,f, input {0,1}, stack {X,$}, accept f. Here X corresponds to the exam's working stack symbol 0; if copying the exact problem, use its required symbol 0.

s — ε,ε→$ → p
p — 0,ε→X → h
h — ε,ε→X → p
p — ε,ε→ε → r
r — 1,X→ε → r       pop one
r — 1,X→ε → u       begin pop two or three
u — ε,X→ε → r       finish pop two
u — ε,X→ε → v       begin pop three
v — ε,X→ε → r       finish pop three
r — ε,$→ε → f

The p→h→p cycle pushes twice per zero. The r choices consume exactly one 1 while popping one, two or three X's. The phase switch forbids zeros after the first one. The final marker check forces exact total balance. ε is accepted. This is the promised construction plus its reason, not merely a diagram that happens to accept one example.

For 001, four markers were pushed but one 1 can pop at most three, so all branches fail to finish. For 011, two markers were pushed; choosing one pop for each 1 empties them and accepts. A requested simulation tree must still show the losing branches.

State limits: store the right thing in the right place

The 2021 paper asks for a PDA with at most two states recognizing binary strings whose number of ones is divisible by six. A six-state DFA would remember the remainder in its state. A PDA can instead store a remainder symbol 1,…,5 on the stack, keeping remainder 0 as empty stack in an accepting control state. It doesn't need an unbounded counter for this problem; its stack alphabet is an alternate finite storage location.

This illustrates a design choice, not a universal shortcut. If the exam restricts Γ, you cannot invent extra symbols to beat the state limit. Write a small table of configuration meanings (control state plus stack top) before drawing arrows.

A minimality proof for a one-state PDA

In the 2020 language B={0ᵐ1ⁿ | m≥n≥0}, ε must accept. A one-state final-state PDA therefore has its only state accepting. It also must accept 01 by some run starting with an empty stack. That same run can be replayed on another 01, leaving any old stack content underneath: it never needs to pop below the level where its own first run began, and ε in a pop field does not test emptiness. The control state is still the same. Thus it accepts 0101, which violates block order. Contradiction.

The model assumptions matter: this is final-state acceptance and the course's no-pop ε convention. Do not transplant the proof unexamined to a model with empty-stack tests or a different acceptance rule.

Turing machines

16. Program a Turing machine on paper

A Turing machine has a tape it can read and write, plus a head that moves. Unlike a stack, you can revisit earlier positions. This lets the machine use marks, repeated scans, and work areas. The exam often gives a plan and asks you to compile it into a precise diagram.

Decode one transition

δ(q,a)=(r,b,R)\delta(q,a)=(r,b,R)δ(q,a)=(r,b,R) means: in state q, reading tape symbol a, write b in that cell, move right, and enter r. a→b,R is the diagram label. a→R is shorthand for a→a,R: keep the symbol, move right.

There is no input-consuming versus ε move distinction like in an NFA. Every step reads the cell under the head, even when that cell is blank. The blank symbol ⊔ is a real tape symbol. It is not ε.

The seven-part definition is (Q,Σ,Γ,δ,q₀,q_accept,q_reject). Σ is the input alphabet; Γ is the tape alphabet and contains the blank and any marks. Standard course definitions exclude blank from Σ. Historical problems can use their own explicit notation; identify any special convention in the question rather than silently changing it.

Entering q_accept or q_reject halts immediately. This differs from a DFA's final-state-at-end rule. The TM must itself perform all needed checks before accepting. A state reached too early does not wait around to read the rest.

Read a configuration

A configuration records current state, tape, and head position. In u q v, the state symbol q is inserted immediately before the cell being scanned, which is the first symbol of v. q is not written on the tape.

Suppose δ(q₀,0)=(q₁,x,R). Then

q₀ 01#01  ⇒  x q₁ 1#01

The old 0 became x; the head now scans 1. If δ(q₁,1)=(q₂,1,L), then

x q₁ 1#01  ⇒  q₂ x1#01

The tape is x1#01 and q₂ scans x. Keep a blank explicitly when the head scans beyond the written input. At the tape's left boundary, the course model keeps the head there if instructed to move left.

A complete toy machine

Task: replace every 0 in a binary input by 1 and halt at the first blank. One working state q does it:

State/read Write Move Next
q / 0 1 R q
q / 1 1 R q
q / ⊔ ⊔ R accept

On 01: q01⊔⇒1q1⊔⇒11q⊔⇒11⊔q_accept⊔. Every step is accounted for, including the halting step. On ε the first cell is blank, so it halts immediately. This isn't a difficult language; it teaches the mechanics needed for a long exam construction.

Build a serious TM from phases

For the slide language {w#w∣w∈{0,1}∗}\{w\#w\mid w\in\{0,1\}^*\}{w#w∣w∈{0,1}∗}:

  1. Select the next unmarked left symbol; mark it x. The state remembers whether it was 0 or 1.
  2. Scan past # to the first unmarked right symbol; compare it and mark it x.
  3. Return across the right block to #, then through the left block until the correct left marker boundary.
  4. Repeat. When no left symbols remain, check that the right side contains only marks, then accept.

Do not merge two return phases if the same read symbol needs different actions. The course's TM 3 page 10 explains why x means “keep moving left” in one phase but “turn around” in another. A state means what job am I currently doing?, including what information must survive the scan.

Proof obligations for a decider

Invariant: after k completed rounds, the first k symbols on each side were equal and are marked; unmarked suffixes are untouched. Correctness: a mismatch rejects; finishing both sides establishes equality; any equal pair can complete all rounds. Halting: each successful round marks another left symbol; finite scans reach a marker or blank; hence only finitely many rounds occur. Do not forget malformed inputs when the problem requires checking them.

A recognizer accepts members but may reject or loop on nonmembers. A decider halts on every input. A correct-looking acceptance trace alone proves neither total correctness nor termination.

Why blank means different things in different phases

At q₃/q₄ a blank is a processed mask bit, so scan right. At q₅/q₆, after the current bit, there are no processed mask blanks ahead: remaining mask bits, separator, then output are nonblank. When all text is erased, q₀ reads the first # and accepts. Equal promised lengths ensure all mask positions have also been processed. Each round processes one pair; every scan crosses a finite region to a guaranteed boundary. Therefore the machine halts. The empty case ## accepts with empty output.

18. More tapes, more branches, same power

Different machine models can look wildly different and still recognize exactly the same languages. “Equivalent” concerns what can be computed, not whether the diagrams, running time, or number of states are identical.

Two tapes: one simultaneous move

A k-tape transition reads k symbols, writes k symbols, and moves k heads, while changing one shared control state. For two tapes,

δ(q,a,b)=(r,c,d,R,L)\delta(q,a,b)=(r,c,d,R,L)δ(q,a,b)=(r,c,d,R,L)

reads a on tape 1 and b on tape 2, writes c,d respectively, moves head 1 right and head 2 left, and enters r. Do not run the tape-1 line as one machine step and the tape-2 line as another. They are one joint instruction.

The course allows a stay move S for multitape machines. The input starts on tape 1; all other tapes are blank. Any extra left marker you want must be a permitted symbol, and its initialization must be part of the construction.

A concrete copy routine

Suppose the tape alphabet permits a marker $. First write $ at the beginning of tape 2 and move its head right, leaving tape 1 at the first input character. For each a∈{0,1}, read a on tape 1 and blank on tape 2; write a on tape 2 and move both heads right. At tape-1 blank, the copy is complete. Move tape-2 head left over copied symbols until $, then right. Now tape 2 is positioned at the copy's first symbol.

This illustrates initialization, simultaneous updates, and boundary detection. It is not a substitute for a past question that restricts Γ={0,1,#,⊔} and forbids $. Under such a restriction you must use the permitted marking strategy or boundary behavior.

Simulating many tapes with one

Encode each tape's used region as a block separated by #. Mark the scanned cell in each block using a dotted version of its symbol. A one-tape simulator scans the blocks to learn the k scanned symbols, remembers that finite tuple in its control, then scans again to perform the prescribed writes and move the marks. If a simulated head needs a fresh cell, insert a blank in that block and shift later material right.

For fixed k and finite Γ, the tuple of scanned symbols has finitely many possibilities, so finite control can remember it. Each simulated step takes finitely many scans. This proves simulation of arbitrary computations, not just a sample trace. The reverse direction is immediate: a one-tape machine is a special case of a multitape machine.

A stay move can also be simulated: write the requested symbol, move right into an intermediate state, then move left while preserving that next cell. Choosing right then left avoids problems at the left boundary.

Nondeterministic TM: why breadth-first matters

An NTM accepts if at least one branch accepts. A depth-first simulator may follow one infinite branch forever while another branch accepts after five steps. So enumerate the tree fairly, by depth: all paths of length 0, then 1, then 2, and so on. Each layer is finite because each configuration has finitely many next moves.

If an accepting branch exists, it has a finite length d, and the breadth-first simulator eventually visits it. Thus a deterministic TM can recognize the same language. This is not NFA subset construction into finitely many control states; TM configurations include arbitrarily long tape contents.

If every branch halts on every input, finite branching implies the computation tree for a fixed input is finite (the relevant consequence of König's lemma). Then exhaustive breadth-first simulation can also reject after all branches finish. This establishes equivalence for deciders too. “Every branch is finite” alone would not imply a finite tree if infinite branching were allowed; finite branching is essential.

Fresh practice

An NTM's left branch loops forever; its right branch accepts after three steps. Describe what a depth-first simulator and a breadth-first simulator might do, and whether the NTM accepts.

Show the answer

The NTM accepts because its right branch accepts. A depth-first simulator choosing the left branch first can loop forever and never discover this. Breadth-first explores all finite depths fairly, so it eventually reaches the right branch's accepting configuration at depth three. This explains recognizer equivalence; it does not make the original NTM a decider, because one branch fails to halt.

Connections

19. Connect the whole course map

This page connects the whole map. Use it after the worked lessons, or jump to a missing definition from another lesson. It is a summary with proof ideas, not a replacement for producing the constructions yourself.

Three levels of memory

Finite automata: finite state only. DFA, NFA, and regular expressions describe the regular languages. An NFA can branch but does not gain language-recognition power over a DFA.

Pushdown automata: finite control plus one unbounded stack. Nondeterministic PDAs and CFGs describe the context-free languages. Every regular language is context-free: a PDA can simulate a DFA while ignoring its stack. Some context-free languages, such as 0ⁿ1ⁿ, are not regular. DPDAs recognize a proper subclass of CFLs.

Turing machines: rewritable tape with a moving head. Multitape and nondeterministic variants have the same recognition power as ordinary deterministic TMs. Deciders halt on every input; recognizers may loop on nonmembers. The ability to simulate another model establishes containment; separating examples establish that a containment is strict.

The published course explicitly omits the detailed non-context-free-language discussion at the end of PDA 5. CFL pumping was absent as a direct task in the six inspected Midterm 2 papers. It is not part of this site's core practice route unless current class information adds it. Regular-language pumping is a separate theorem and must not be used to prove a language is not context-free.

Regular-language closure: what “closed” means

A class is closed under an operation if applying that operation to languages in the class always produces another language in the class. “Open” is not the usual opposite term here; say “not closed.” One result being regular does not establish closure of the whole class.

Regular expressions and GNFA elimination

RE operations are union, concatenation and star. ε denotes the language {ε}; ∅ denotes the empty language. Therefore Rε=R, R∅=∅, R∪∅=R, and ∅*=ε. Concatenation order matters.

Both DFA→GNFA and NFA→GNFA can be done directly. Add a new start with an ε edge to the old start, a new sole accept reached by ε from old finals, union parallel edges, and label missing edges ∅. An NFA's symbol and ε labels are already regular expressions. Subset construction is not required for this route.

A proof template that travels

For any conversion, write: what does a state/variable/configuration represent; why is that true at the start; how is it preserved by each move/rule; why does the ending condition correspond to membership? For a decider, add why the process halts. For equivalence, cover both directions. For impossibility, identify a property forced by every candidate machine and construct an input that violates it.

The Church–Turing thesis connects the informal notion of an effective algorithm with Turing computation. It is a thesis about that informal notion, not a mathematical theorem proved by checking a few programs. The course's Hilbert deck uses integer-root search to contrast a recognizer with a bounded terminating decision procedure.

The fresh s accepts ε. A completed 01 finishes at w and may begin another complete copy through u. The strings 01 and 0101 accept; 001 and 01001 reject. There is no zero self-loop here. Adding a zero self-loop at u would make 001 possible; that would change the language and break this construction. The accepting new start does not grant arbitrary extra input a free pass: some path still has to consume the entire input.

How to study with this book

Reading an explanation and producing a proof from a blank page are different skills. This workbook trains both. The target is strong performance on unfamiliar exam questions, including exact procedures and complete justification.

The daily loop

  1. Retrieve before rereading. Start with one previously studied task. Write what you remember on paper. Then check it.
  2. Learn one complete example. Read the problem, its purpose, each transition or proof step, and why that step is justified. Follow the linked slide pages when the original diagram matters.
  3. Close it and produce. Solve a related task without copying the example. If you need help, use the hint; record the attempt as assisted.
  4. Repair the first broken link. Was it notation, the mechanism, the procedure, choosing a method, or proving the claim? Relearn that link, then attempt a different example.
  5. Return after a delay. Aim for the next day, roughly three days later, then a week later. These are adjustable defaults, not a scientifically optimal schedule. Mix related topics after you can attempt their basic procedures.

The daily page suggests one lesson and shows locally due practice. It doesn't turn a click or a streak into a claim of mastery. Your attempt history distinguishes needs work, assisted, independent once, and later recall. These are self-reports; this static site does not grade mathematical proofs.

Why this design

Worked examples and explicit modelling reduce the amount a novice must invent at once. Guidance should then fade into independent work rather than remain a permanent stream of answers. The AERO guides and the worked-example meta-analysis support that sequence, with important differences across learners and tasks. AERO explicit teaching, AERO scaffolding, Barbieri et al., 2023.

Retrieval practice and spacing generally improve later access to knowledge. Trying to reconstruct a proof or diagram can reveal gaps that rereading hides. Transfer to changed problems needs deliberate practice too; recalling a familiar sentence is not enough. Agarwal et al., 2021, Carpenter et al., 2022, Latimier et al., 2021.

The latest review checked here, published October 29, 2026, finds classroom benefits of retrieval, spacing and interleaving, with variation across contexts and limited evidence for some moderators. Those are population-level findings, not a promise about one exam or an optimal schedule for one student. Ruitenburg et al., 2026.

For proofs, ask what licenses a crucial step and how it connects to the claim. Research on self-explanation training supports proof comprehension; it does not establish that reading explained proofs automatically produces independent proof-writing skill. This is why the workbook has both a complete proof and a fresh task. Hodds, Alcock & Inglis, 2014.

Feedback should identify the error, the violated condition, and the next correction. “Wrong” and “great job” alone give little direction. Wisniewski et al., 2020. Explanations are useful when they connect reasons; demanding an explanation of every tiny step can add load. Rittle-Johnson, 2024. Concrete examples and formal statements should be explicitly connected. IES practice guide.

AI can help during practice while leaving independent performance weaker if it supplies answers too freely. One high-school mathematics field experiment found this risk and evidence that tutoring safeguards mitigated it. That result motivates hidden solutions and independent retests here; it does not diagnose any particular student's result. Bastani et al., 2025.

What demanding theory courses actually recommend

Stanford CS103 separates creative problem-solving from formal proof writing, explicitly teaches assumptions and conclusions, and checks variable scope and justified claims. Its exam review advises working on weak material and writing an answer before consulting solutions. We adopt those observable course practices. They are teaching guidance, not evidence that every high-scoring student follows one secret routine. Guide to proofs, Proofwriting checklist, Exam review, pages 3–6.

There is no established single “best” method for every learner and every task, and university prestige is not causal evidence. The strongest practical combination here is accurate modelling, meaningful independent attempts, specific feedback, delayed retrieval, and varied exam tasks. We adjust it from demonstrated work rather than claiming it already works for you.

A practical study block

Use about 45–60 minutes as a starting structure: 5–10 minutes recalling an earlier task, 15–20 minutes following one worked example, 15–20 minutes attempting and checking a fresh problem, and a few minutes recording the next repair. These times are planning choices. If a concept breaks, spend the block repairing it; reading more pages doesn't compensate for a missing dependency.

For daily reading on a phone, study the explanation and trace a small example. For exam practice, use paper and close the lesson. During a mixed mock, set the timer, keep solutions shut, and review only after the block. Use the attempt record to note solution exposure. A problem whose answer you remember is useful recall practice, but is not a fresh independent test.

What a 90+ target requires

Aim to complete representative unseen or meaningfully changed questions under the actual exam constraints, with correct constructions, complete proofs, and enough time to check the requested format. Review with the supplied rubric and official solutions, and ask for a mathematical review of your own written work when available. An answer that “looks familiar” is not evidence of that level. No reading-completion percentage or practice score guarantees 90+.

Before an exam: confirm current scope and logistics; account for every requested subpart; respect state and alphabet limits; test ε and shortest legal inputs; check all nondeterministic branches when a tree is required; finish TM simulations; name the contradiction or prove both directions as appropriate.

Problem 1 · Grammar and normal form · 25 points

Let Σ={a,b}, V={S,A,B}, and

S → AB | A
A → aA | a
B → bB | ε

(a) Give a leftmost derivation of aab. (4)

(b) Prove this grammar is ambiguous using aa. Give two leftmost derivations. (6)

(c) Convert to CNF. Show a new start, ε elimination, unit elimination, and final helper rules. (15)

Review Problem 1 after your attempt

(a) S⇒AB⇒aAB⇒aaB⇒aabB⇒aab. (b) S⇒A⇒aA⇒aa, and S⇒AB⇒aAB⇒aaB⇒aa. The start choices differ and both derivations are leftmost.

(c) Add S₀→S. Only B is nullable. Removing B→ε adds S→A (already present) and B→b; the grammar now has S→AB|A, A→aA|a, B→bB|b. Eliminate units S→A and S₀→S: S₀→AB|aA|a; S→AB|aA|a; A→aA|a; B→bB|b. Introduce U→a and W→b: S₀→AB|UA|a; S→AB|UA|a; A→UA|a; B→WB|b; U→a; W→b. No start ε rule is permitted: the original language contains at least one a.

Rubric: 4 for a valid leftmost derivation; 6 for two distinct leftmost derivations of the same string and the conclusion. CNF: new start 2, correct nullable alternatives and ε removal 4, unit elimination 4, legal final shapes 3, all stages shown 2. A language-changing omission needs correction even if a few strings still derive.

Problem 2 · Build and justify a PDA · 25 points

Construct a PDA for L={0m1n2n∣m≥0,n≥1}L=\{0^m1^n2^n\mid m\geq0,n\geq1\}L={0m1n2n∣m≥0,n≥1} with at most five states and Γ={X,$}. Give its states, start, accepting set, transitions, and a proof of both directions. Trace 01122 through acceptance, and explain why 002 is rejected.

Review Problem 2 after your attempt

Use Q={s,p,r,t,f}, start s, F={f}, Σ={0,1,2}. Moves: s —ε,ε→$→ p; p —0,ε→ε→ p; p —1,ε→X→ r; r —1,ε→X→ r; r —2,X→ε→ t; t —2,X→ε→ t; t —ε,$→ε→ f. All unspecified δ entries are ∅; each listed PDA output is a singleton pair set.

Every accepting run consumes only zeros in p, at least one 1 to reach r, and at least one 2 to reach t. X markers count unmatched ones; reaching f requires all removed. Thus every accepted string has the required form and counts. Conversely, every such string can take m zero loops, n pushes, n pops, and the bottom-marker finish.

Trace: (s,01122,ε)→(p,01122,$)→(p,1122,$)→(r,122,X$)→(r,22,XX$)→(t,2,X$)→(t,ε,$)→(f,ε,ε). For 002, after the zeros the machine remains in p with next symbol 2, for which there is no move. It rejects.

Rubric: correct construction under constraints 10; formal components and transition types 4; soundness and completeness 6; full accepting trace 3; rejection explanation 2. Recheck ε and inputs with no ones: n≥1 is essential.

Problem 3 · PDA-to-CFG conversion · 20 points

A normalized PDA has states {s,p,r,f}, start s, sole accept f, and transitions:

s — ε,ε→$ → p
p — a,ε→X → p
p — b,X→ε → r
r — b,X→ε → r
r — ε,$→ε → f

(a) State why the normalization conditions hold. (4)

(b) Define the variables and start variable, give every wrapped rule with a pairing table, and specify the other two rule families. (12)

(c) Derive aabb from the start variable. (4)

Review Problem 3 after your attempt

(a) f is the only accepting state, and its only entrance pops $ after all X markers. Every transition pushes or pops exactly one symbol. (b) Variables Aᵢⱼ for i,j∈{s,p,r,f}; start Aₛf. Pair $ push s→p with pop r→f to get Aₛf→Aₚr. Pair X push p→p on a with pop p→r on b to get Aₚr→aAₚpb; pair it with pop r→r on b to get Aₚr→aAₚrb. Other families: Aᵢⱼ→AᵢₖAₖⱼ for all i,j,k and Aᵢᵢ→ε for all i. (c) Aₛf⇒Aₚr⇒aAₚrb⇒aaAₚpbb⇒aabb.

Rubric: normalization 4; variables/start 3, three correct pairings 6, two remaining families 3; valid derivation 4. A wrong inner index changes the meaning even if the surrounding terminals look right.

Problem 4 · Turing-machine construction · 20 points

Input is promised to be w# followed by blanks, where w is a nonempty binary string. Compute the bitwise complement of w in place, leave # unchanged, and halt immediately to the right of #. Use only L/R moves and at most two working states, plus accept and reject. Give a complete transition table over Γ={0,1,#,⊔}, trace 01#, and justify halting. Explain what changes if the input promise is removed and ε must be rejected.

Review Problem 4 after your attempt

Under the promise, one working state q suffices: on 0 write 1,R,q; on 1 write 0,R,q; on # write #,R,accept; on blank write blank,R,reject. Trace: q01#⊔⇒1q1#⊔⇒10q#⊔⇒10#q_accept⊔. After k scanned bits, exactly the first k bits are complemented and the remainder unchanged. Each move goes right, so the finite input reaches # and halts.

Without the promise, specify the desired valid format first. If it must be nonempty binary w followed by exactly one # and then blank, use a separate initial state requiring 0 or 1, and a state after # to check blank. A straightforward strict validator uses three working states: initial, scan, and check-after-separator. This is a construction, not a minimality claim; do not assume the original two-state constraint is automatically retained. The question asks what changes, not to force an unjustified minimal state count.

Rubric: table with correct writes/head movement 8; entire trace 4; invariant and halting 5; promise/validation distinction 3. The trace alone does not establish correctness for all promised inputs.

Problem 5 · Pumping with a changed boundary · 10 points

Prove L={0m1n∣m>2n, n≥1}L=\{0^m1^n\mid m>2n,\ n\geq1\}L={0m1n∣m>2n, n≥1} is not regular. Explicitly give the witness string and pumping repetition, and cover every legal split.

Review Problem 5 after your attempt

Suppose L is regular with pumping length p≥1. Choose s=0²ᵖ⁺¹1ᵖ∈L, of length 3p+1≥p. For every split s=xyz with |xy|≤p and |y|>0, y=0ᵏ for some 1≤k≤p. Choose i=0. Then xy⁰z=0²ᵖ⁺¹⁻ᵏ1ᵖ has at most 2p zeros and p ones, violating m>2n. This contradicts pumping, so L is nonregular.

Rubric: assumption/arbitrary p 1; valid long witness 2; all-splits argument 3; specific pumping count and failed condition 3; contradiction/conclusion 1. An argument choosing a single convenient split is incomplete, even if its arithmetic is right.
